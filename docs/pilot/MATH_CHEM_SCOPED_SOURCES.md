# Mathematics and Chemistry controlled-pilot source pass

This pass uses seven private NCDC PDFs: Lower Secondary Mathematics and Chemistry syllabuses (2019), Advanced Secondary Chemistry and Principal Mathematics syllabuses (2025), the shared Advanced Secondary assessment framework (2026), and the two matching subject assessment guidelines (2026).

The files belong at the exact gitignored paths in `knowledge-tools/catalog/pilot-source-catalog.json`. Check document title, level, subject, year and original SHA-256 before mapping a newly supplied PDF to one of those paths. Keep the original files unchanged.

From the repository root, run:

```bash
python3 knowledge-tools/build_source_registry.py --scope pilot-math-chem
python3 knowledge-tools/extract_corpus.py
python3 knowledge-tools/validate_corpus.py
```

The default registry command without `--scope` still requires the full catalogue. The scoped registry uses the seven listed pilot sources and reports `blocked_subjects` when any required source is missing. It excludes that subject's incomplete source set while allowing unrelated complete subjects to proceed. A missing shared framework blocks both Advanced Secondary subjects. It does not invent records for missing sources. Generated registry, page spans, candidates, and review files remain under gitignored `knowledge-sources/`.

The scoped registry uses `pilot-operator-authorization.json` to bind the founder's explicit `OPERATOR_AUTHORIZED_FOR_PILOT` decision to the SHA-256 of each of the seven supplied PDFs. A changed PDF fails that match. The authorization covers controlled-pilot use only; it does not assert public-domain or general redistribution rights. The database import still begins at `UNKNOWN`; the privileged, checksum-bound `record_knowledge_pilot_operator_authorization` decision must be recorded after import before pilot retrieval or release activation. The full-corpus registry remains unchanged.

The scoped extractor uses syllabus-specific table anchors for topics, subtopics, competency statements, periods and class applicability. It excludes contents, front matter, page headings, captions and column headings from runtime topics. Seven remaining syllabus layout cases were resolved against the source PDFs; the rebuilt syllabus review queue is empty. The remaining 74 open review items concern detailed Advanced Secondary assessment mapping. A zero-error structural validator result alone is not an academic verification decision. No import or publication is part of these commands.

The founder's two academic rulings are recorded in `knowledge-tools/catalog/pilot-academic-decisions.json` against the exact source checksums. Chemistry construct mapping uses the AO table on guideline PDF pages 9–10, while the differing labels on page 26 remain in source provenance. The framework uses the written five-times maximum-score rule on PDF page 21; its contradictory worked example remains visible, and score bands are not derived from it. A changed source checksum cannot inherit either ruling. These rulings settle those two interpretation choices only; they do not verify the surrounding assessment tables or release records.

The assessment review also writes `knowledge-sources/review/human-review/assessment-page-decisions.jsonl`. It identifies each specimen item/sample-rubric page and publisher back cover by source checksum and PDF page. These pages remain in the private source spans but are excluded from normative assessment-profile rules. The framework's pilot-subject Table 1 rows and both guidelines' AO-to-construct/topic Table 1 rows are extracted separately; a Principal Mathematics row spanning pages 9–10 retains both page references. Twelve individually reviewed AO/summary/written-scoring records have exact-record SHA-256 decisions in `knowledge-tools/catalog/pilot-verification-decisions.json`. The extractor emits the applied subset to `knowledge-sources/review/human-review/verified-record-decisions.jsonl`. A changed source checksum, page reference, or normalized/wording content invalidates the decision. These decisions do not verify adjacent assessment tables or any syllabus records.

The founder's syllabus decision is `knowledge-tools/catalog/pilot-curriculum-verification.json`. It is limited to the four approved syllabus checksums, parser versions and the curriculum-only dataset checksum. `python3 knowledge-tools/pilot_curriculum_release.py` validates physical PDF checksums, page wording, period headings, hierarchy, provenance, relationship endpoints/types and the empty syllabus review queue before generating the two private manifests in `knowledge-sources/derived/releases/`. The general candidate status stays `REVIEW_REQUIRED`; governed membership plus the checksum-bound `OPERATOR_VERIFIED_FOR_PILOT` decision admits those exact records to controlled-pilot curriculum runtime. Assessment candidates are excluded. `python3 knowledge-tools/pilot_runtime_acceptance.py` checks deterministic curriculum context assembly for all four profiles.

The one-teacher planner and application are `src/pilot-readiness/one-teacher-bootstrap.ts` and `src/pilot-readiness/one-teacher-application.ts`. The narrow database RPC in `drizzle/0043_one_teacher_controlled_pilot_application.sql` requires an existing Auth teacher and a server-managed pilot-operator claim. It stages independently keyed sections and a draft one-teacher timetable from explicit form data. The existing timetable activation workflow materializes scheduled lessons after assignments are confirmed. The teacher confirms curriculum position separately; the bootstrap never writes a position confirmation.

The curriculum release set is **Lower Secondary 2019** with Mathematics and Chemistry and **Advanced Secondary 2025** with Chemistry and Principal Mathematics. Both manifests are `CURRICULUM_RUNTIME_READY` and `ASSESSMENT_RUNTIME_NOT_READY`. The 2026 framework and subject guidelines remain separate, inactive assessment candidates. There is no Subsidiary Mathematics profile. No effective date is invented.
